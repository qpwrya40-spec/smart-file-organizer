# Smart File Organizer

A simple open-source Python tool that automatically organizes files into folders based on their file type.

## Features

- Images → Images
- Videos → Videos
- Audio → Audio
- Documents → Documents
- Archives → Archives
- Other files → Other

## Requirements

Python 3.9 or newer.

## Usage

Run:

python organizer.py

Then enter the path of the folder you want to organize.
